# The Duel: source models

Full-size files as they came from Meshy, kept here because Meshy's download links expire.
`main` holds the shrunk versions the game loads (see `tools/build_models.mjs` there).

- `sun_warlord_rig.glb`, `varek_rig.glb`, `plate_knight_rig.glb`: rigged fighters on the shared humanoid skeleton.
- `combat3_anim.glb`: the combat motions bought for The Duel (Combat Stance, Walk Fight Forward, Triple Combo Attack,
  Charged Slash, Thrust Slash, Charged Ground Slam, Sword Parry, Roll Dodge, Hit Reaction to Waist, Knock Down).
- `*.json`: the Meshy task ids each fighter was made from.

Earlier motion files (`combat_anim.glb`, `combat2_anim.glb`, `villager_m_anim*.glb`) are on the `models` branch of forgeframehq/rts-game.
